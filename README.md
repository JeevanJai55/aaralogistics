# AARA Logistics — Next.js 3D Website

## What is included

- Cinematic AARA home page with procedural Three.js logistics scene.
- Separate solution pages:
  - `/services/first-mile`
  - `/services/middle-mile`
  - `/services/last-mile`
  - `/services/quick-commerce`
  - `/services/warehouse-solutions`
- Scroll-driven GSAP motion and Lenis smooth scrolling.
- Mobile navigation and responsive layouts.
- User-provided logistics explainer video, color-graded and sharpened for web presentation.
- Warehouse automation section showing AMR movement, robotic picking and human-machine collaboration using original CSS/HTML illustrations.
- AARA metrics, Why Choose AARA, service coverage and contact information supplied in the project brief.

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Reference approach

The information architecture for the solution pages takes inspiration from public logistics-company patterns such as CoreMile's separation of product/service areas, technology, operational proof and contact flows, without copying its design or wording. See https://www.coremilesolutions.com/.
